# bloging-app

A statically generated blog for `blog.cursedshrine.com`, built and
served from the Pi behind the existing Cloudflare tunnel.

Goal: publish original, data-backed technical writing (Pi/homelab
incident writeups, build logs, benchmarks) and monetise it — ads as
a floor, affiliate and own-product as the real upside.

Status: **planning**. No code yet. Stack decision recorded, awaiting
Gaurav's sign-off before scaffolding.

## Where things live

- `.claude/project-infrastructure/` — infra docs (stack, host,
  tunnel, deploy, risks, monetisation constraints)
- `.claude/history/` — dated record of every significant change
